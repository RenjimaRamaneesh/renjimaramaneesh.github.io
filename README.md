# Renjima Ramaneesh | Mobile & Applied AI

A responsive personal portfolio with 40 searchable project entries, project-detail dialogs, professional experience, technical expertise, education and contact links.

## Preview

Open `index.html` in a browser. No installation, build step, backend or API key is required.

## Hosting

Designed for GitHub Pages. Publish the repository's `main` branch from `/ (root)` in Settings > Pages.

## Editing

- `index.html`: introduction, featured work, experience, skills, education and contact details.
- `projects.js`: project descriptions, categories, technology tags and public links.
- `styles.css`: layout and responsive styling.
- `app.js`: search, filters and accessible project dialogs.
